鼠标连点器 1.0.0

系统要求：macOS 13 或更新版本；支持 Apple Silicon 和 Intel。

安装
1. 将「鼠标连点器.app」拖到 Applications 文件夹。
2. 从「应用程序」启动鼠标连点器，然后推出安装磁盘。
3. 点击「前往授权」，在系统设置的「隐私与安全性 → 辅助功能」中启用本应用。
4. 选择点击间隔、左右键和次数，点击开始，并在 3 秒内将鼠标移到目标位置。

Control + Option + 空格：开始 / 停止。
Esc：停止。

本版本为本地 ad-hoc 签名，未通过 Apple Developer ID 签名和公证。
从互联网下载后，macOS 可能阻止首次打开。如果你确认信任此来源，可在尝试打开后，
按系统「隐私与安全性」中的提示选择「仍要打开」。请不要关闭系统整体安全保护。

无需安装 Xcode、Swift 或下载源码。
